## 何时需要 ADR

满足任一条即需：

- 改**地基判据**（六轴 / `⪯` / 六要件 / 事件模型 / 视觉通道表）
- 引入**新的架构层**（新实体、新存储、新同步机制）
- **推翻既有决策**（尤其推翻 `../reference/not-list.md` 中的条目）
- 选择**有长期代价**的方案（如引入 codegen 全家桶、引入第二套时钟）

## 不必写 ADR 的情形

- 只改常量数值（B 级变更，PR 说明即可）
- 只改措辞、补例子（C 级）
- 界面排布细节（TBD 级）
