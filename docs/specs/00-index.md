### 二.2 三份作废交付物的作废形态

**为什么单列**：`B3` / `B12` 作废后留下三份交付物，它们**没有都采用同一种作废手法**，而各自文件头只写自己的依据、不写「为什么三份不一样」。缺了这张总账，下一个人看到 `channel-table` 全文被注释、`constants` 却还在一节节标红，会以为有人漏做了。

| 交付物 | 作废形态 | 残余价值怎么保 | 主要引用点 | 清偿 |
|---|---|---|---|---|
| [`VIEW-views.md`](VIEW-views.md)（40 条） | **整卷封存**：头部横幅 + 正文整体包进 HTML 注释 | 「§树的四类行」与 `VIEW-014`「点星 ⇒ 详情」的分派原则 → 交给 `B17a`，**重新裁定、不继承编号** | `STD` 里 `VIEW-*` 的用例挂靠（**押后**，见 §二.1 清偿顺序） | `B17a` 落地后重写 |
| [`channel-table.md`](channel-table.md) | **整卷封存**：同上 | ① 一通道一维度（`X-02`）② §三 的豁免论证**方法** ③ §五 的排除清单 | `entity-fields` · `VIEW` · `SDP` · 本文件 §三 | `B17b` 建新表后删 |

> **形态不同，判据是同一条**：残余价值是**条目级**还是**整表级**。`constants` 90 条里 34 条还在跑 ⇒ 只能分层；`VIEW` / `channel-table` 的地基整块不存在、逐条改等于重写（`VIEW` 里 `Z0`–`Z4` 出现 **258 处**）⇒ 只能整卷封存。
> **⚠️ 三份里只有一份带运行期风险**：`C-55` / `C-56` **仍在代码里跑**（接 `GalaxyLayout.spun()` 与 `StarSystemLayout.advanced()`）。**文档标废不等于代码停了** —— 随 `B13a` 删 `features/universe/` 时一并停用，**不得只删文档留代码**。其余两份是纯文档，标废即生效。

## 四、跨文档约束清单

以下判据**同时约束多份文档**，拆开后单看任何一份都看不见它的全貌。此为索引存在的第二个理由。

| 约束 | 内容 | 管着哪几份 |
|---|---|---|
| **X-01 未声明即不渲染** | 模型未声明的通道 / 字段 / 分区，界面不得画出来；缺失表现为空位或不画，不补默认值 | FND · VIEW · NOTE |
| **X-02 一通道一维度** | 每个视觉通道只承载一个语义维度；唯一豁免是轨道环（掌握填充 + 毕业线型） | VIEW · QUANT |
| **X-03 不同构就不映射** | 宇宙坐标与树缩进不同构 ⇒ 只做交叉淡入；`φ` 不得当难度代理；难度不得进 Planner 预览 | VIEW · QUANT |
| **X-04 事件是唯一事实源** | 所有可写状态由 `fold(events, asOf)` 得出；不得有并行的可写状态表 | PACK · STEP · NOTE · GOV |
| **X-05 验证不得自证** | 验收须给可观测断言与测试向量；不以「代码里写了」充当验收 | 全部（每份末验收表） |
| **X-06 声明驱动零分支** | 空间 / 语言 / 方法差异由内容包与平台声明承载，代码不得按具体空间分支 | PACK · PLAN · STEP |
| **X-07 已学不可撤销** | `item_passed` 是 append-only 事件；只有包版本迁移可改变其指向 | QUANT · PACK · GOV |
| **X-08 顺序与范围分离** | 体系（顺序）定义在空间级；`target`（范围）随视距。不得给域单独配体系 | FND · PLAN · NOTE |
| **X-09 同步只搬不判** | 同步层只搬运事件与校验包版本，**不去重、不做冲突解决、不计算状态**；合并一律由客户端 `fold` 完成。违反它不会有任何测试变红 —— 故须显式成条 | SYNC · GOV · PACK |

> ⚠️ **`X-01`–`X-03` 与 `X-08` 的表述对象已不存在，但内核仍然成立**。这四条的**判据**（不补默认值 / 一通道一维度 / 不同构不映射 / 范围与顺序分离）在新本体下全部照样适用；失效的只是它们各自举例的「通道」「`φ` 坐标」「视距」这些词。重写 `VIEW` 时一并改写措辞，**本文件不先行改写** —— 在没有新档位定义之前改写，等于再猜一次。

## 五、编号规则

格式 **`SPEC-<域>-<NNN>`**，每份从 001 起。每条附 `src:` 字段记来源（讨论轮次或依据文档），用于回溯。

**为什么重编**：讨论期的临时编号有真实撞车 —— `Z1–Z4` 同时指「视距档位」与「跨设备合并批次」，`S1–S4` 与 FSRS 的 `S` 撞，`M1–M4` 与里程碑撞。规格里写「Z3 触发」时无法判断指哪个。**这不是洁癖，是可读性的必要条件。**

## 七、变更纪律

| 变更级别 | 判据 | 动作 |
|---|---|---|
| **C 级** | 只改措辞、补例子 | 直接改，PR 里说明 |
| **B 级** | 改常量数值、改字段可空性、新增事件类型 | PR + 变更说明 + 回填横切表 |
| **A 级** | 改地基判据（三轴容器树 · 地形层 `⪯` · 事件模型 · 四类包 · 身份与地址分离） | 先出 ADR，**评审通过后同一批内改规格并登 §二.1** |
| **D 级** | 与 NOT 清单冲突 | **不做**；除非推翻 NOT 条目并留痕 |

> ⚠️ **A 级原本只写「先出 ADR，评审通过后改规格」，`ADR-0005` 只做了前半** —— 规格滞后至今，而期间没有任何东西变红。这正是 §二.1 存在的理由：规则要求两步，缺了第二步不会有反馈，只会让下一个读规格的人按旧前提开工。**故 A 级判据补上「同一批内」与「登 §二.1」两个约束。**

规格是活文档，**不设版号**。交付物按 `ADR-0009` 移出本仓托管，不再参与本仓的版号体系。
