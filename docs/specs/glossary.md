# 术语表

> **唯一权威处**：术语定义与辨析只在本文件维护。设计文档引用术语时**不重新定义**。

## 一、核心术语

| 术语 | 定义 |
|---|---|
| **KST 三元组** | 知识项 `Q` · 学习者状态 `K` · 前提偏序 `⪯`。全案的理论地基 |
| **知识空间（`space`）** | ⛔ **已作废** —— 「一空间一包」被四类包取代（`ADR-0005` 决策 2）。容器子树的新形态见 [`entity-fields`](entity-fields.md) §2 八槽位表 |
| **域（`domain`）** | ⛔ **已作废** —— 「域」是五档径向投影的中间容器层。新本体改由**槽位**表达，见 [`skeleton-catalog`](skeleton-catalog.md) |
| **知识项** | 可学的最小单元，KST 中的 `Q`。实现上是 `Node` 的两分之一 —— **`LearnableNode`**（恒在 `planet` 槽位），另一分是 `StructuralNode`。见 [`ADR-0007`](../decisions/0007-node-type-shape.md) |
| **结构节点** | 只承载树形位置、不可学的容器，五槽位（`axis` / `group` / `galaxy` / `cluster` / `star`）之一。与「可学节点」**互斥且穷尽** |
| **前提偏序（`⪯`）** | 项之间的 DAG 依赖。⚠️ **现在挂在独立的地形层**：`PrerequisiteEdge`，`strength ∈ required / recommended`；`⪯` 定义为 **`required` 边的传递闭包**，不再从「体系」或「层深」推出（`ADR-0005` 决策 4） |
| **体系（`Scheme`）** | ⚠️ **不再是「`⪯` 的线性扩展」** —— 改为**跨轴 route**：一串有序节点，相邻两跳之间必须有树边或虫洞边，且不得违反 `required` 偏序。三条机器校验见 `ADR-0005` §二 `PLAN` 行 |
| **目标集（`target`）** | 一次 Plan 圈定的项集合。⚠️ 原有的「粒度随视距（`Z1`≈150 / `Z3`≈12 / `Z4`=1）」随视距一并失效，新粒度口径待 `B17a` 重定 |
| **圈内 / 圈外** | 圈内 = 本空间正式收录的项；圈外 = 有边相连但未收录（可申请纳入） |
| **六要件** | 边界 / 证成 / 命题 / 关联 / How / Tacit。每格三态：齐 / 缺 / **不可外化** |
| **三轴** | 学科 / 专业 / 角色。**容器轴** —— 每轴独立成树，槽位深度不等（5 / 5 / 6）。⚠️ **取代原「六轴」**：六轴是索引坐标、不构成容器，而新本体里**轴就是树**（`ADR-0005` 决策 1） |
| **槽位（`level_slot`）** | 节点在轴内的层级名（`axis` / `group` / `galaxy` / `cluster` / `star` / `planet`）。**存槽位名而非层号** —— 三轴实际占用的槽位不同，用绝对层号会让「第 3 层」在三轴各指不同东西 |
| **三层** | 持久 / 视图 / 快消。知识的保鲜周期。（概念不变；原「驱动形态通道」一句随六通道作废） |
| **视距 `Z0`–`Z4`** | ⛔ **已作废** —— `ADR-0005` 决策 3 取消五档径向投影 |
| **六通道 / 叠加通道** | ⛔ **已作废** —— 见 [`channel-table`](channel-table.md) 头部。⚠️ 但**原则「一通道一维度」（`X-02`）仍然成立**，只是通道本身要重定 |
| **`overlay`** | ⚠️ 原为「叠加在 pack 之上的内容层，双平面」。现拆成 **`OverlayPatch`**（对某节点的字段级补丁）+ **`PathClaim`**（自建路径的认领墓碑）+ **`PathAlias`**（改名后的旧路径别名）。见 `entity-fields` |
| **执行算子** | 学习动作的 6 类原语：读 / 例 / 忆 / 练 / 讲 / 做。`MethodProfile` 只能排这 6 个 |
| **脚手架** | 学习时可用的辅助：提示（`hint`）、看答案。**用了最高判合格** |
| **掌握度（`mastery`）** | `d × s`。`d` = 要件深度，`s` = `S` 的饱和归一。**连续、可回落** |
| **进度** | 已学项数 / 圈内项数。**离散、永不倒退** |
| **已学** | ⑤ 首次验收合格（判据为空时 = 步骤跑完）。**不可撤销** |
| **毕业** | `S ≥ 180` 天，转为「可用能力」。**不可逆** |
| **黑洞** | **未知知识**：有痕迹（有边指向它）、无实体。表现为空位 + 指向边 |
| **游离项** | 在 `target` 内但未被体系覆盖的项。单列「未纳入路径」分组 |
| **overlay** | 叠加在 pack 之上的内容层。双平面：本地（自己可见）/ 公共（审核后） |
| **HLC** | 混合逻辑时钟：`{physical, counter, deviceId}`。离线可生成且保证全序 |

## 二、必须分清的八对概念

### ① 坐标 vs 容器 —— ⛔ 已作废，且结论反转

原辨析成立的前提是「六轴是索引坐标、不是容器」。`ADR-0005` 决策 1 取消了这个二分：**三轴各自就是树**，每一轴都满足「唯一父级 / 能层层打开 / 能放内容 / 有边界」。

⚠️ **由此带来一条结论反转，必须注意**：原文写「『计算机 → 编程语言 → Python』是**三次筛选**，不是三次下钻」—— 在新本体下**正好相反，它是三次下钻**。凡引用旧结论的地方一律作废。原「『计算机专业』不升级为容器，除非它自己持有 `Item`」这句同样失效：现在它本来就是容器。

### ② 定位算子 vs 执行算子

| | 定位算子（五族 17 个） | 执行算子（6 类） |
|---|---|---|
| 做什么 | **找到**知识在坐标里的位置 | 对一项**做一个学习动作** |
| 谁执行 | 引擎（索引计算） | 人（在界面上操作） |
| 用在哪 | 定位三态 · 六要件校验 | `MethodProfile.steps[]` |
| 出处 | 方法论文档 §6 | 由已定六个方法反推 |

**「算子必须在册」这句话没错，错在指错了册。** 五族 17 个里没有一个能当「讲一遍」「跟读」「默写」。

### ③ 掌握度 vs 进度

| | 掌握度 | 进度 |
|---|---|---|
| 形态 | 连续值 `[0,1]` | 离散分数（已学 / 圈内） |
| 会回落吗 | **会** | **不会** |
| 视觉 | 轨道环填充比例 | 进展视图 · 计划进度 |
| 用途 | 判断「学得多牢」 | 判断「还剩多少」 |

**两者是两套独立数据，不是同一个数的两种画法。** 混用会导致「复习没考好 → 进度倒退」这种荒谬表现。

### ④ 复习 ≠ 重学

复习只执行标了 `phase: review` 的步骤（忆 / 讲 / 默写类），**不重跑**「读定义 → 看例子」。否则复习耗时约等于初学，每日配额第三天就会爆表。

### ⑤ 体系 vs 目标集

- **体系**是**顺序**，现在是**跨轴 route**（一串有序节点 + 三条机器校验），不再是 `⪯` 的线性扩展 —— 跨轴之后就谈不上「线性扩展」了：`⪯` 只在同一轴内成立。
- **目标集**是**范围**（`target`），粒度口径待 `B17a` 重定。

**「想只学语法那部分，是收窄 `target`，不是另配一套体系」这条仍然成立。** 变的是体系的构成方式：原来只能在同一个空间的一套 `⪯` 里选顺序，现在可以跨轴串（专业 → 角色），但**仍不得为同一段范围配两套并行顺序**。

### ⑥ 层不是树层级 —— ⚠️ 缩进规则待 `B17a` 重定

原判据「树的第一层用域、不用层」建立在「域」这个容器层上，**域已作废**。但 `layer` 仍然不是树层级 —— 它现在挂在 `LearnableNode` 上，表达知识保鲜周期，与树的槽位无关。

新的缩进规则随 `B17a`（容器树七级）重定。在此之前**不得用 `layer` 当缩进依据** —— 这一条与旧版结论一致，变的是理由。

### ⑦ 跳过 vs 未过

| | 跳过 | 未过 |
|---|---|---|
| 语义 | 「今天不想做」 | 「做了但没达标」 |
| 写判定事件吗 | **不写** | 写 `item_graded(未过)` |
| 计 `failCount` 吗 | 不计 | 计 |
| 处置 | 移出本次会话，留到下次 | 累计 2 次判前置缺 |

**连续 3 次跳过 → 只给提示（弱信号），不硬判缺口。**

### ⑧ 黑洞 vs 圈外项

| | 黑洞 | 圈外项 |
|---|---|---|
| 有实体吗 | **没有** | 有 |
| 有内容吗 | 没有 | 有，但不在本空间正式收录内 |
| 树里怎么画 | 虚线占位（父位取指向边的源点质心） | 圈外虚线支线（只画一层） |
| 用户能做什么 | 走 D5 提审补内容 | **申请纳入** |

## 三、被废止的说法（出现即视为错误）

| 错误说法 | 正确说法 | 说明 |
|---|---|---|
| 「力导向布局」 | **容器树 + 同心球壳**（球壳半径 = 轴内槽位深度） | 3D 力导向**永久排除**，见 `not-list.md`。⚠️ 本条原写的「正确说法 = 坐标定位（`r`/`θ`/`φ`）」已废；**结论不变、理由换了** —— 位置由容器层级决定，不由力平衡决定 |
| 「暗物质」 | 已并入黑洞概念 | 不再单列 |
| 「双星」 | 归入边（关系） | 星体形态不承载关系维度 |
| 「用轴内深度估难度」 | 不相干 | 槽位深 ≠ 难度，违反「不同构不映射」（原表述为「用 `φ` 估难度」，`φ` 已废，原则不变） |
| 「笔记按 `carry` 分摊」 | 笔记**全额复制** | `carry` 只折算记忆状态，不折算文本 |
| 「方法 = 平台层」 | 方法候选有**三处出处**：平台 / 包 / 自建 | 单说「平台层」会把自建排除在外 |
| 「结构化表单是首期主要输入」 | **输入框为主 + 表单兜底** | 真实输入双峰分布，表单只吃中间那档 |
| 「难度分布」进 Planner 预览 | 预览只有三项：项数 / 分母 / 时长 | 建计划时 `D` 尚不存在 |
| 「跨容器统一队列」 | 角标挂在容器层 + 概览页按容器聚合 | 跨容器比 `due` 是伪排序（原表述为「跨空间」，`Z1` 角标已随视距作废） |
| 「打卡项能毕业」 | **永不毕业** | `S` 永不增长 ⇒ 永不到 180 |
