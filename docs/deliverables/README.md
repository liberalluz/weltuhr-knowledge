## 二、与设计基线的关系（重要）

交付物**引用不复制**设计规格。具体做法：

- SRS 的每条需求挂 `SPEC-<域>-<NNN>` 编号，正文只写需求陈述与验收标准，不复制判据理由；
- SDD 的分章与 `design/` 的八份主题对齐，实现细节回指；
- STP 的测试用例直接用 `design/` 每份末的**验收表**（裁定号 / 可观测断言 / 测试向量 / 预期）作为种子。

**这样做的理由**：设计基线会随讨论演进，交付物按版号冻结。若复制，「设计改了交付物没改」必然发生。
