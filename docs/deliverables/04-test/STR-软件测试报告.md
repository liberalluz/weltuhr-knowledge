## 一、不追溯说明

`2026-10-17` 之前的测试执行**不补写**。本文件属**记录类**文档，价值在「当时跑出来是什么结果」；事后补写会让证据变成叙述 —— 读者无法分辨哪些行是当场记下的。

前史（S0 + 内容包管线）的实际执行证据保留在 CI 运行记录与各 PR 正文里，可直接溯源：PR `#1`–`#13`。

**与 `STP` / `STD` 的区别**：这两份是**承诺类**（「应当怎么测」「有哪些用例」），当前状态可补录，故由追溯补录补齐。

### 轮次格式（新增时照此填）

| 项 | 填什么 |
|---|---|
| 轮次 | `R<n>` + 日期 |
| 触发 | 哪个批次 / 哪个 PR |
| 环境 | 本机 / CI / 真机；**沙箱跑不了的项须标注「未验 + 原因 + 归谁验」** |
| 结果 | 逐项：用例编号 · 通过与总数 · 实际输出片段 |
| 未通过项 | 现象 · 复现步骤 · 处置（修 / 降级 / 记为已知问题） |

> **不得写「应该能跑」**。未执行的项要么不写，要么明确标「未验」并写明由谁在何处验。
