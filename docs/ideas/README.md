# ideas —— 还没认定的想做什么

> **本目录当前为空，这是有意的**：空目录本身就是信息 —— 目前没有悬而未决的候选。

## 判据：与 `intent/` 的唯一分界是**时态**

| 目录 | 定义 | 被引用时的身份 |
|---|---|---|
| [`intent/`](../intent/) | **已经认定的为什么** —— 论证与依据，不随实现改动 | 作为**依据**引用（「因为 `ADR-0005` 的论证如此」） |
| `ideas/`（本目录） | **还没认定的想做什么** —— 候选，尚未被接受成决策或规格 | 作为**候选**引用（「这里有个想法，还没定」） |

**一条内容该放哪，问一句就够**：它被接受过吗？

- 接受过，且讲「为什么」→ [`intent/`](../intent/)
- 接受过，且讲「应当如何」→ [`specs/`](../specs/)
- 接受过，且讲「定没定」→ [`decisions/`](../decisions/)
- **没接受过 → 这里**

## 三条纪律

- **不得代填结论**。想法就是想法：写「倾向 X」可以，写「定为 X」不行 —— 后者是决策，该进 `decisions/`。与 `open-decisions` 台账同规：**倾向不等于结论，实施者不得据倾向开工**。
- **不得作为实施依据**。读到这里的内容一律不得直接动手；要动手先把它推成 `decisions/` 的一条裁定，或推成 `specs/` 的一条规格。
- **认定后迁出，不留在原地**。某条想法被接受时，正文迁到承接它的目录，本目录删行 —— 不在两处各留一份。

目录分工与版号口径见 [`../README.md`](../README.md) §一；目录级红线见 [`../AGENTS.md`](../AGENTS.md)。
