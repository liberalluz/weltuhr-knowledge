# 未决事项台账（Open Decisions）

> **为什么单列**：「先记下来、等讨论」的口头承诺在跨会话时必然丢失 —— 每一条都在某次讨论里被提出、被认定「要拍」，然后因为没有落点而消失。**台账不是待办列表**，它是「已经识别出、但还没裁定」的口径集合：**裁定一旦作出，条目迁出本文件**（进 ADR、进规格、或进 [`not-list.md`](not-list.md)），此处删行不留尸。
> **与 `not-list.md` 的分工**：`not-list` 记**已裁定不做**（结论 + 理由）；本文件记**尚未裁定**（议题 + 备选 + 挡谁）。两者是同一根轴的两端，**不得互相抄写**。
> **与 SDP §4.5 的分工**：§4.5 记「**行政 / 外部前置**」（谁去办、办到没有）；本文件记「**口径未定**」（拍哪个值）。前者是办事，后者是决策。

## 四、本文件维护纪律

- **一条一行**，编号 `OD-nn` **不复用**；裁定后从 §一 移到 §二 索引，**裁定正文不在此复制**。
- 每条必须写全 **议题 · 现状证据 · 阻挡谁 · 备选（≥2）· 倾向与理由**。缺「阻挡谁」的不收 —— 不挡任何东西的议题不该占台账。
- **不得代填答案**：只记备选与倾向，**最终值由裁定人拍**。倾向不等于结论，实施者不得据「倾向」直接开工。
- **裁定当笔必须同时改落点**：只把条目移进 §二 索引、不写落点，等于「裁了没落」，比待决更糟 —— 它会让人以为已经解决了。
