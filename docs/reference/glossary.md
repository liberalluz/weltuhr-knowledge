# 术语表

> **唯一权威处**：术语定义与辨析只在本文件维护。设计文档引用术语时**不重新定义**。

## 一、核心术语

| 术语 | 定义 |
|---|---|
| **KST 三元组** | 知识项 `Q` · 学习者状态 `K` · 前提偏序 `⪯`。全案的理论地基 |
| **知识空间（space）** | 一个有边界、可进入的内容单元。一空间一包，独立版本 |
| **域（domain）** | 空间内的分区，对应 Z2 星云。**不是**独立空间 |
| **知识项（`Item`）** | 可学的最小单元，KST 中的 `Q` |
| **前提偏序（`⪯`）** | 项之间的 DAG 依赖。决定「先学什么」 |
| **体系（`Scheme`）** | `⪯` 的一个**线性扩展** = 一条具体的学习顺序。其逆序数可非零 |
| **目标集（`target`）** | 一次 Plan 圈定的项集合。粒度随视距：Z1 ≈150 / Z3 ≈12 / Z4 = 1 |
| **圈内 / 圈外** | 圈内 = 本空间正式收录的项；圈外 = 有边相连但未收录（可申请纳入） |
| **六要件** | 边界 / 证成 / 命题 / 关联 / How / Tacit。每格三态：齐 / 缺 / **不可外化** |
| **六轴** | 学科 / 岗位 / 行业 / 能力 / 主题 / 技术栈。**索引坐标**，非嵌套层级 |
| **三层** | 持久 / 视图 / 快消。知识的保鲜周期，驱动形态通道 |
| **视距 Z0–Z4** | 宇宙 / 星系（空间）/ 星云（域）/ 恒星系（局部子图）/ 单星（项） |
| **六通道** | 形态 / 大小 / 亮度 / 虚实 / 颜色 / 边样式。**一通道一维度** |
| **叠加通道** | 轨道环（掌握 + 毕业）· 脉动（SRS 调度） |
| **执行算子** | 学习动作的 6 类原语：读 / 例 / 忆 / 练 / 讲 / 做。`MethodProfile` 只能排这 6 个 |
| **脚手架** | 学习时可用的辅助：提示（`hint`）、看答案。**用了最高判合格** |
| **掌握度（`mastery`）** | `d × s`。`d` = 要件深度，`s` = `S` 的饱和归一。**连续、可回落** |
| **进度** | 已学项数 / 圈内项数。**离散、永不倒退** |
| **已学** | ⑤ 首次验收合格（判据为空时 = 步骤跑完）。**不可撤销** |
| **毕业** | `S ≥ 180` 天，转为「可用能力」。**不可逆** |
| **黑洞** | **未知知识**：有痕迹（有边指向它）、无实体。表现为空位 + 指向边 |
| **游离项** | 在 `target` 内但未被体系覆盖的项。单列「未纳入路径」分组 |
| **overlay** | 叠加在 pack 之上的内容层。双平面：本地（自己可见）/ 公共（审核后） |
| **HLC** | 混合逻辑时钟：`{physical, counter, deviceId}`。离线可生成且保证全序 |

## 二、必须分清的八对概念

### ① 坐标 vs 容器

| | 坐标（六轴） | 容器（空间 / 域） |
|---|---|---|
| 一个东西能有几个 | 多个，同时成立 | 只有一个父级 |
| 能否层层打开 | 不能 | 能 |
| 能否往里放内容 | 不能 | 能 |
| 有边界吗 | 没有 | 有 |
| 点击效果 | 改筛选（`axisFilter`） | 换根 / 进入 |

**典型误判**：「计算机 → 编程语言 → Python」是**三次筛选**，不是三次下钻。「计算机专业」不升级为容器，除非它自己持有 `Item`。

### ② 定位算子 vs 执行算子

| | 定位算子（五族 17 个） | 执行算子（6 类） |
|---|---|---|
| 做什么 | **找到**知识在坐标里的位置 | 对一项**做一个学习动作** |
| 谁执行 | 引擎（索引计算） | 人（在界面上操作） |
| 用在哪 | 定位三态 · 六要件校验 | `MethodProfile.steps[]` |
| 出处 | 方法论文档 §6 | 由已定六个方法反推 |

**「算子必须在册」这句话没错，错在指错了册。** 五族 17 个里没有一个能当「讲一遍」「跟读」「默写」。

### ③ 掌握度 vs 进度

| | 掌握度 | 进度 |
|---|---|---|
| 形态 | 连续值 `[0,1]` | 离散分数（已学 / 圈内） |
| 会回落吗 | **会** | **不会** |
| 视觉 | 轨道环填充比例 | 进展视图 · 计划进度 |
| 用途 | 判断「学得多牢」 | 判断「还剩多少」 |

**两者是两套独立数据，不是同一个数的两种画法。** 混用会导致「复习没考好 → 进度倒退」这种荒谬表现。

### ④ 复习 ≠ 重学

复习只执行标了 `phase: review` 的步骤（忆 / 讲 / 默写类），**不重跑**「读定义 → 看例子」。否则复习耗时约等于初学，每日配额第三天就会爆表。

### ⑤ 体系 vs 目标集

- **体系**是**顺序**（`⪯` 的线性扩展），定义在**空间级**，一个空间一套 `⪯` 只能派生出若干候选序列。
- **目标集**是**范围**（`target`），随视距变化。

**想只学语法域，是收窄 `target`，不是给语法域另配一套体系。** 反之「给某个域单独选体系」等于要求空间内存在多套排序，与「独立 `⪯`」判据直接冲突。

### ⑥ 域 vs 层（树的缩进规则）

树的第一层用**域**，不用**层**。`Item.layer` 是**径向属性**（驱动形态通道），不是层级；把它当缩进会与视距体系冲突。层在树里按**行尾标签**处理。

### ⑦ 跳过 vs 未过

| | 跳过 | 未过 |
|---|---|---|
| 语义 | 「今天不想做」 | 「做了但没达标」 |
| 写判定事件吗 | **不写** | 写 `item_graded(未过)` |
| 计 `failCount` 吗 | 不计 | 计 |
| 处置 | 移出本次会话，留到下次 | 累计 2 次判前置缺 |

**连续 3 次跳过 → 只给提示（弱信号），不硬判缺口。**

### ⑧ 黑洞 vs 圈外项

| | 黑洞 | 圈外项 |
|---|---|---|
| 有实体吗 | **没有** | 有 |
| 有内容吗 | 没有 | 有，但不在本空间正式收录内 |
| 树里怎么画 | 虚线占位（父位取指向边的源点质心） | 圈外虚线支线（只画一层） |
| 用户能做什么 | 走 D5 提审补内容 | **申请纳入** |

## 三、被废止的说法（出现即视为错误）

| 错误说法 | 正确说法 | 说明 |
|---|---|---|
| 「力导向布局」 | 坐标定位（`r`/`θ`/`φ`） | 3D 力导向**永久排除**，见 `not-list.md` |
| 「暗物质」 | 已并入黑洞概念 | 不再单列 |
| 「双星」 | 归入边（关系） | 星体形态不承载关系维度 |
| 「用 `φ` 估难度」 | 不相干 | 层深 ≠ 难度，违反「不同构不映射」 |
| 「笔记按 `carry` 分摊」 | 笔记**全额复制** | `carry` 只折算记忆状态，不折算文本 |
| 「方法 = 平台层」 | 方法候选有**三处出处**：平台 / 包 / 自建 | 单说「平台层」会把自建排除在外 |
| 「结构化表单是首期主要输入」 | **输入框为主 + 表单兜底** | 真实输入双峰分布，表单只吃中间那档 |
| 「难度分布」进 Planner 预览 | 预览只有三项：项数 / 分母 / 时长 | 建计划时 `D` 尚不存在 |
| 「跨空间统一队列」 | Z1 角标 + 概览页空间级 | 跨空间比 `due` 是伪排序 |
| 「打卡项能毕业」 | **永不毕业** | `S` 永不增长 ⇒ 永不到 180 |
