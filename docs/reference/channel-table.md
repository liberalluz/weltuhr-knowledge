## 三、唯一豁免的说明（必须原样保留在实现评审清单里）

轨道环一个通道承载两个维度，是**对「一通道一维度」的显式豁免**，理由是：

1. 填充比例与线型是**同一视觉对象上互相独立的两个自由度**，不产生歧义（一个看「多牢」，一个看「能不能用」）；
2. 线型在本体系内已有既定语义（实线 = 确定、虚线 = 不确定），毕业与否正是「确定可用 / 尚未确认」；
3. 若为此新增第七通道（光晕、光环），才是真正的破坏。

> **本豁免不得作为先例。** 任何「再往某通道里塞一个维度」的提议，须证明「新维度用的是该对象上未被占用的自由度，且与该通道既有语义同源」，否则一律驳回。

## 五、不得用于视觉表达的语义（重要）

| 语义 | 为什么不能进视觉 | 正确落点 |
|---|---|---|
| 难度 `D`（FSRS） | 首次学习前不存在，且 `φ` 不是难度代理（不同构） | 进展视图（学过一次后）、详情页 |
| 进度百分比 | 进度是**离散项数**，与掌握度是两套数据 | 进展视图 · 计划进度分区 |
| 打卡式 / 验证式 | 是可信度标签，不是空间属性 | 详情页 · 进展视图（`progressKind` 标记） |
| 源档位（`official` / `standard` / `textbook` / `reference` / `community`） | 是元数据，与视觉无关 | Planner 候选卡 · 详情页来源区 |
